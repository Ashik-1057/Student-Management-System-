# 🎓 Student Management System - JDBC

**Technologies Used:** Jframe + MySQL + JDBC

### 📌 Project Description
এটা একটা Desktop Based Student Management System. Java Jfream দিয়া GUI বানানো আর MySQL + JDBC দিয়া Database Connect করা হইছে।

### 🚀 Main Features
- 🎓 Add, Update, Delete Student Records
- 📊 Student Grade & Result Management


### 🛠️ Tech Stack
- **Backend:** Jfream, JDBC
- **Database:** MySQL
- **IDE:** NetBeans

### ⚡ How to Run This Project
1. **Database Setup:** 
   - MySQL Open করো
   - `student_db` নামে Database Create করো
   - `database.sql` ফাইল Import করো

2. **Project Setup:**
   - NetBeans এ Project Open করো
   - `DBConnection.java` 
   - MySQL Connector JAR File Add করো

3. **Run:**
   - `Main.java` ফাইল Run করো
